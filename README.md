# ☕ Figuras Geométricas en Java

Aplicación desarrollada en **Java** para calcular áreas y perímetros de diferentes figuras geométricas, aplicando conceptos de **Programación Orientada a Objetos (POO)**.

Este proyecto fue desarrollado como parte de mis prácticas académicas en Ingeniería en Inteligencia Artificial.

## 🎯 Objetivo

Aplicar conceptos fundamentales de Java y programación orientada a objetos mediante la creación de diferentes clases que representan figuras geométricas.

## 📐 Figuras implementadas

El proyecto incluye las siguientes figuras:

- ⚪ Círculo
- ▭ Rectángulo
- ◼️ Cuadrado
- 📐 Triángulo rectángulo
- 🔷 Trapecio

Cada clase contiene los atributos y métodos necesarios para realizar los cálculos correspondientes.

## 📁 Estructura del proyecto

- `Circulo.java` — cálculo del área y perímetro de un círculo.
- `Rectangulo.java` — cálculo del área y perímetro de un rectángulo.
- `Cuadrado.java` — cálculo del área y perímetro de un cuadrado.
- `TrianguloRectangulo.java` — cálculos correspondientes a un triángulo rectángulo.
- `Trapecio.java` — cálculo del área y perímetro de un trapecio.
- `PruebaFiguras.java` — clase principal utilizada para crear los objetos y comprobar el funcionamiento de las figuras.
